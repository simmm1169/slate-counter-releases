# Slate Counter

**Current version: 1.0.21**

## Install on a phone
1. Open this page on the phone in Chrome.
2. Tap **[Download SlateCounter.apk](https://github.com/simmm1169/slate-counter-releases/raw/main/SlateCounter.apk)**.
3. Open the downloaded file and tap **Install**. The first time, Android asks to allow installing from Chrome: allow it.

## Updates
The app checks for new versions each time it opens and offers **Install**.
You can also tap **Check for update** at the bottom of the app.
